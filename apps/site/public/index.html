Intégrations

Des intégrations ouvertes, sans restriction dans le plan Gratuit

Branchez vos agents, vos forges git et vos outils d'alerte. Chaque intégration est disponible dès le premier utilisateur.

  • Claude CodeAgentLit et met à jour vos issues par le serveur MCP de Telic.
  • CodexAgentSe connecte au serveur MCP et travaille sur vos issues.
  • CursorÉditeurAjoutez Telic comme serveur MCP dans l'éditeur.
  • Gemini CLIAgentInterroge et modifie vos issues depuis le terminal.
  • WindsurfÉditeurLe même serveur MCP, dans votre éditeur.
  • MCPProtocoleLe serveur MCP de Telic expose projets, issues et cycles aux agents IA.
  • GitHubForge gitReliez vos dépôts GitHub à vos projets.
  • GitLabForge gitReliez vos dépôts GitLab à vos projets.
  • GiteaForge gitVotre forge auto-hébergée fonctionne aussi.
  • BitbucketForge gitReliez vos dépôts Bitbucket à vos projets.
  • SentryErreursLes erreurs Sentry arrivent dans un état de triage.
  • TelegramBotRecevez vos notifications par le bot Telegram.
  • WebhooksSortantsEnvoyez les événements de Telic vers vos services.
